# Module 8: Local Development & Validation

Welcome to Module 8!

Historically, Databricks development happened entirely in the browser-based UI. Today, modern Data Engineering teams develop locally in their IDEs (like VS Code) and utilize robust CI/CD practices.

In this module, you will learn how to build, test, and deploy code like a Senior Engineer:
1. **[Lesson 8.1: Local Unit Testing with Pytest](lesson-8.1-local-pyspark-and-pytest.md)** - Write unit tests using an in-memory local Spark session.
2. **[Lesson 8.2: Interactive Debugging with Databricks Connect](lesson-8.2-databricks-connect.md)** - Execute queries in Azure directly from your VS Code terminal.
3. **[Lesson 8.3: Integration Testing with Databricks Asset Bundles](lesson-8.3-asset-bundles-and-integration.md)** - Deploy entire workflows to a Dev workspace for integration testing.

Start with [Lesson 8.1](lesson-8.1-local-pyspark-and-pytest.md).
